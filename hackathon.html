Glosario Fácil: La Inteligencia Artificial Explicada con Peras y Manzanas

💬 1. Prompt

Es la instrucción o pregunta que tú le escribes a la IA. Entre más claro y específico seas con tu orden, mejor será el resultado.

🧩 2. Token

Son los pedacitos en los que la IA divide las palabras para leerlas (como sílabas). 100 palabras son aproximadamente 130 tokens.

🗺️ 3. Embedding

Es como la "huella digital" del significado de una frase. Permite buscar ideas parecidas aunque usen palabras completamente diferentes.

📖 4. RAG (Recuperación)

Es como hacer un examen a libro abierto: en lugar de que la IA responda de memoria, le pasas tus documentos para que lea la respuesta correcta.

👓 5. LoRA (Adaptación)

Ponerle unos lentes de aumento especializados al modelo para que aprenda un formato especial o jerga técnica sin gastar millones de dólares.

⚡ 6. VRAM (Memoria GPU)

La memoria ultra rápida de la tarjeta gráfica donde vive el cerebro de la IA mientras piensa. En Google Colab te prestan 15 GB gratis.

Pieza 1 rag_engine.py · El Buscador de Documentos de tu Proyecto

Este código guarda los textos de tu negocio y encuentra automáticamente el párrafo que responde la pregunta del usuario:

rag_engine.py 
import numpy as np
from sentence_transformers import SentenceTransformer

class VectorRAGEngine:
    def __init__(self, model_name="all-MiniLM-L6-v2"):
        # Cargamos el modelo traductor de texto a vectores de significado
        self.embedder = SentenceTransformer(model_name)
        self.documentos = []
        self.embeddings = None

    def index_documents(self, docs: list[str]):
        # Guarda tus textos y calcula sus huellas digitales en segundos
        self.documentos = docs
        self.embeddings = self.embedder.encode(docs, normalize_embeddings=True)

    def search(self, pregunta: str, top_k=2, umbral_minimo=0.40):
        # Compara la pregunta contra todos los textos y devuelve los 2 mas parecidos
        q_emb = self.embedder.encode([pregunta], normalize_embeddings=True)[0]
        similitudes = np.dot(self.embeddings, q_emb)
        mejores_indices = np.argsort(similitudes)[::-1][:top_k]
        
        resultados = []
        for idx in mejores_indices:
            if similitudes[idx] >= umbral_minimo:
                resultados.append({"texto": self.documentos[idx], "confianza": float(similitudes[idx])})
        return resultados

Pieza 2 router.py · El Mesero Inteligente

Filtra si la persona está saludando amablemente o si está preguntando algo de la empresa:

router.py 
class ModelRouter:
    def __init__(self):
        # Palabras clave que indican que debemos buscar en tus documentos
        self.palabras_documento = ["politica", "reembolso", "devolucion", "garantia", "envio", "precio", "costo"]
        self.palabras_formato_json = ["json", "esquema", "ticket", "ficha"]

    def route(self, mensaje_usuario: str) -> str:
        texto = mensaje_usuario.lower()
        
        # Si pregunta por politicas -> Usamos RAG
        if any(p in texto for p in self.palabras_documento):
            return "RAG_PIPELINE"
            
        # Si pide un formato tecnico -> Usamos el formateador JSON
        if any(p in texto for p in self.palabras_formato_json):
            return "LORA_ADAPTER"
            
        # Si es un saludo normal -> Respuesta directa
        return "FAST_LLM"

Pieza 3 api_server.py · El Servidor Web para Conectar a Internet

Permite que cualquier persona o aplicación web consulte a tu asistente a través de un endpoint HTTP seguro:

api_server.py 
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel
import time

app = FastAPI(title="Mi Asistente de IA - Proyecto Hackathon", version="1.0.0")

# Definimos la forma del mensaje que nos envian
class MensajeEntrada(BaseModel):
    mensaje: str
    usuario: str = "invitado"

# Definimos la forma de la respuesta que entregamos
class RespuestaSalida(BaseModel):
    respuesta: str
    tiempo_milisegundos: float
    fuente: str

@app.post("/v1/chat", response_model=RespuestaSalida)
async def chatear(entrada: MensajeEntrada):
    inicio = time.perf_counter()
    if not entrada.mensaje.strip():
        raise HTTPException(status_code=400, detail="Por favor escribe un mensaje valido.")
    
    # Aqui se procesa el mensaje con RAG o el LLM
    tiempo = (time.perf_counter() - inicio) * 1000
    return RespuestaSalida(
        respuesta="¡Hola! Segun nuestras politicas oficiales: los reembolsos se gestionan en 30 dias con ticket.",
        tiempo_milisegundos=round(tiempo, 2),
        fuente="Politica_Devoluciones_Art4"
    )
Primeros Auxilios · Solución de Problemas

Resolución Rápida de Dudas y Tropiezos Frecuentes

¿Tuviste algún tropiezo o duda técnica? Consulta las soluciones con explicaciones sencillas:

1. ¿Cómo hago para que la IA nunca invente cosas que no están en mis textos? Cero Alucinaciones

En tu prompt del sistema agrega esta regla de oro: "Responde únicamente usando el texto del Contexto. Si el Contexto no contiene la respuesta, di textualmente: 'No cuento con información oficial sobre este tema en mis manuales'." Además, fija el umbral_minimo = 0.40 en tu RAG para ignorar textos que no tengan que ver.

2. ¿Qué hago si me sale un error rojo de `CUDA Out of memory` en Colab? Memoria VRAM

Significa que le pediste a la tarjeta gráfica más de lo que puede cargar a la vez. Solución súper fácil: Cambia el modelo a uno de 1B (como TinyLlama/TinyLlama-1.1B-Chat-v1.0 o meta-llama/Llama-3.2-1B-Instruct) o fija per_device_train_batch_size = 1.

3. ¿Cómo puedo subir mis propios archivos PDF o Word a Google Colab? Archivos Propios

En Google Colab, haz clic en el icono de carpetita a la izquierda y arrastra tu archivo .txt o .pdf. En Python puedes leerlo fácilmente con with open("mi_archivo.txt") as f: textos = f.readlines() y pasarlo directo a rag.index_documents(textos).

4. ¿Cómo pruebo mi servidor FastAPI desde el navegador? Swagger UI

Cuando ejecutes tu servidor localmente, abre en tu navegador http://localhost:8000/docs. Verás una pantalla interactiva con botones para mandar mensajes de prueba y ver las respuestas al instante.

5. ¿Cómo forzar al modelo a que conteste estrictamente en formato JSON? Formato JSON

Pon 2 ejemplos claros en el prompt mostrando cómo empieza con { y termina con }. Indícale: "Responde únicamente con el bloque JSON, sin introducciones ni despedidas."

6. ¿Qué pasa si Google Colab se desconecta por inactividad? Sesiones Colab

No te preocupes. Solo vuelve a darle clic a "Conectar" en la esquina superior derecha y dale "Ejecutar todas las celdas" (Runtime → Run all). Todo tu código se vuelve a cargar en menos de 1 minuto.
