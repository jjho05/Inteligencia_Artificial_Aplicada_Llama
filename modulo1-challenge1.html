1. Fundamentos de Modelos de Lenguaje y Trade-Offs de Escala

1.1 Inferencia y Costos La decisión arquitectónica entre 20B, 120B y 27B

En sistemas de producción, seleccionar el modelo de mayor cantidad de parámetros (como 120B o 70B) para todas las tareas es un error de diseño costoso. Cada token generado por un modelo autorregresivo demanda tiempo de cálculo y memoria SRAM/HBM proporcional a su volumen de pesos:

$$\text{Costo Total} = \left(\frac{\text{Tokens Prompt}}{1{,}000{,}000} \times \text{Tarifa Entrada}\right) + \left(\frac{\text{Tokens Completion}}{1{,}000{,}000} \times \text{Tarifa Salida}\right)$$

Para consultas estándar de atención al cliente (como restablecimiento de contraseñas u horarios de servicio), el modelo compacto openai/gpt-oss-20b proporciona respuestas precisas y estructuradas con una latencia inferior a 1 segundo, reduciendo la factura operativa en más del 70% frente a modelos masivos.

Modelos Evaluados en este Challenge
  • openai/gpt-oss-20b (Ligero): Optimizado para ultra-baja latencia y resolución reactiva de FAQs.
  • openai/gpt-oss-120b (Grande): Capacidad masiva de síntesis, tablas extensas y análisis multifactorial.
  • qwen/qwen3.6-27b (Qwen 27B): Modelo de razonamiento profundo con cadena de pensamiento explícita (filtrada con Regex).

3. Código de Inferencia Multi-Modelo

Código modular de ejecutar_challenge.py estructurado para capturar latencias con time.time() y limpiar las etiquetas internas de razonamiento con expresiones regulares:

Python · ejecutar_challenge.py 
# Challenge 1: Comparador de Modelos Llama
# Alumno: Ing. Jesús Javier Hernández Olvera
# Módulo: IA Aplicada con Modelos Abiertos

import os, re, time
from groq import Groq
from dotenv import load_dotenv

load_dotenv()
client = Groq(api_key=os.environ.get("GROQ_API_KEY"))

MODELO_LIGERO = "openai/gpt-oss-20b"
MODELO_GRANDE = "openai/gpt-oss-120b"
MODELO_QWEN   = "qwen/qwen3.6-27b"

def limpiar_respuesta(texto):
    if not texto: return ""
    return re.sub(r"<think>.*?</think>", "", texto, flags=re.DOTALL).strip()

preguntas = [
    "¿Cómo puedo restablecer mi contraseña olvidada en el portal web institucional?",
    "¿Cuál es el horario de atención y los canales oficiales para soporte técnico?",
    "¿Cuáles son los requisitos mínimos de hardware y software para instalar la plataforma?"
]

def consultar_pregunta(pregunta, num):
    # Inferencia en los 3 modelos
    t0 = time.time()
    r_lig = client.chat.completions.create(model=MODELO_LIGERO, messages=[{"role":"user", "content":pregunta}], max_tokens=600)
    dt_lig = time.time() - t0

    t1 = time.time()
    r_grd = client.chat.completions.create(model=MODELO_GRANDE, messages=[{"role":"user", "content":pregunta}], max_tokens=600)
    dt_grd = time.time() - t1

    t2 = time.time()
    r_qwn = client.chat.completions.create(model=MODELO_QWEN, messages=[{"role":"user", "content":pregunta}], max_tokens=600)
    dt_qwn = time.time() - t2

    return {
        "pregunta": pregunta,
        "modelo": MODELO_LIGERO,
        "respuesta": limpiar_respuesta(r_lig.choices[0].message.content),
        "tiempo_segundos": round(dt_lig, 2),
        "tokens_totales": r_lig.usage.total_tokens,
        "modelo_grande": MODELO_GRANDE,
        "respuesta_grande": limpiar_respuesta(r_grd.choices[0].message.content),
        "tiempo_grande": round(dt_grd, 2),
        "tokens_grande": r_grd.usage.total_tokens,
        "modelo_qwen": MODELO_QWEN,
        "respuesta_qwen": limpiar_respuesta(r_qwn.choices[0].message.content),
        "tiempo_qwen": round(dt_qwn, 2),
        "tokens_qwen": r_qwn.usage.total_tokens
    }

4. Preguntas Frecuentes y Resolución de Dudas

¿Por qué el modelo de 20B es suficiente para FAQs y soporte de primer nivel?

Porque las consultas frecuentes de atención al usuario requieren instrucciones ordenadas y redacción clara, sin demandar razonamiento matemático de múltiples etapas. El modelo de 20B resuelve el 100% de estas consultas con latencias menores a 1 segundo y un costo computacional reducido.

¿Por qué Qwen genera texto en inglés dentro de la etiqueta <think>?

Durante el entrenamiento de modelos de razonamiento (Reinforcement Learning), el modelo descubre autónomamente que el idioma inglés posee mayor densidad semántica en sus pesos para deducir pasos intermedios. Posteriormente sintetiza la respuesta en español. La función limpiar_respuesta() descarta la cadena interna entregando una salida limpia.

¿Qué es el patrón arquitectónico 'Model Router'?

Consiste en interponer un clasificador de intenciones antes de invocar el LLM. Si la consulta es una FAQ o solicitud rutinaria (85-90% del volumen), se enruta al modelo ligero de 20B; si contiene ambigüedad o lógica condicional compleja, se escala a Qwen 27B o GPT-OSS 120B.
