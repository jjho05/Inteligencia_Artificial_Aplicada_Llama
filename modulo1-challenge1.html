import os
import re
from groq import Groq
from google.colab import userdata

# Lectura de la API Key desde Colab Secrets
client = Groq(api_key=userdata.get('GROQ_API_KEY'))

# Resolución dinámica de modelos activos en Groq
def obtener_modelo(client, preferido, alternativo):
    try:
        activos = [m.id for m in client.models.list().data]
        return preferido if preferido in activos else alternativo
    except Exception:
        return alternativo

modelo_ligero = obtener_modelo(client, "llama-3.1-8b-instant", "openai/gpt-oss-20b")
modelo_grande = obtener_modelo(client, "llama-3.3-70b-versatile", "openai/gpt-oss-120b")
modelo_qwen   = obtener_modelo(client, "qwen/qwen3.6-27b", "qwen/qwen3.6-27b")

def limpiar_respuesta(texto):
    if not texto: return ""
    return re.sub(r"<think>.*?</think>", "", texto, flags=re.DOTALL).strip()

print("Cliente de Groq inicializado correctamente.")
print("Modelos configurados para evaluación:")
print(f"  • Modelo Ligero: {modelo_ligero}")
print(f"  • Modelo Grande: {modelo_grande}")
print(f"  • Modelo Qwen: {modelo_qwen}")

Paso 2 · Celda 2

DE PALABRAS A TOKENS

Fundamentos de Tokenización BPE (Byte-Pair Encoding)

Antes de que Llama genere una sola palabra, tu prompt se divide en tokens. Los Large Language Models no comprenden letras ni palabras completas como los humanos, sino secuencias de enteros generadas por un algoritmo de tokenización (como Tiktoken con vocabulario de 128,000 tokens en la familia Llama 3).

  • Vocabulario Extendido (128k): Llama 3 expandió su diccionario respecto a Llama 2 (32k), mejorando la compresión de texto en español en más de un 15%.
  • Ratio Palabras a Tokens: En español, 1 palabra equivale en promedio a ~1.3 a 1.7 tokens debido a los caracteres con tilde y terminaciones verbales.

Q&A: ¿Por qué no contamos caracteres o palabras en lugar de tokens? 1 pregunta resuelta

Porque la arquitectura Transformer procesa matrices de vectores donde cada token representa una posición en la ventana de contexto. Las APIs de inferencia y la memoria VRAM están delimitadas por tokens máximos (ej: 8,192 o 128,000 tokens), no por longitud de texto en caracteres.

En asistentes de preguntas frecuentes, fija siempre temperature=0.2 o temperature=0.0 para obtener respuestas reproducibles, precisas y sin alucinaciones.

Paso 3 · Celda 3

PRIMERA LLAMADA A LLAMA (ZERO-SHOT)

Mecánica de Inferencia Zero-Shot & Generación Auto-Regresiva

Un LLM predice el siguiente token más probable, no busca la respuesta en una base de datos. Vamos a enviar el prompt a Llama en modo zero-shot (sin ejemplos previos) y ver la respuesta generada.

  • Estructura de Mensajes: Compatible con la especificación de Chat Completions usando roles ("system", "user", "assistant").
  • Parámetro max_tokens: Limita el número máximo de tokens de salida generados por el modelo para evitar respuestas infinitas o costos no controlados.
03_primera_llamada_zeroshot.py 
# Enviar el prompt a Llama en Groq y mostrar la respuesta generada

response = client.chat.completions.create(
    model=modelo_ligero,
    messages=[{"role": "user", "content": prompt}],
    max_tokens=500
)

print(response.choices[0].message.content)

La RAM (memoria de acceso aleatorio) es la memoria de trabajo temporal donde la computadora carga los programas y datos en uso activo para que la CPU los procese a gran velocidad. Al apagar el equipo, su contenido se borra (memoria volátil).

En cambio, el almacenamiento (disco SSD o HDD) es la memoria secundaria permanente donde se guardan el sistema operativo, los archivos y aplicaciones de forma persistente aunque la máquina no tenga energía.

Q&A: ¿Qué significa choices[0]? ¿Puede haber más de una elección? 1 pregunta resuelta

Sí. Si pasas el parámetro n=3 a la API, el modelo generará 3 respuestas alternativas independientes para el mismo prompt. Por defecto n=1, por lo que siempre se accede al elemento en el índice 0.

Paso 4 · Celdas 4 y 5

INSPECCIÓN DE LA RESPUESTA COMPLETA & CUÁNTOS TOKENS CONSUMIÓ EL PROMPT

Estructura del Payload de Respuesta & Modelo de Facturación

La respuesta de la API trae un resumen (usage) con el número de tokens de entrada y de salida. Es la forma más directa de responder: ¿cuántos tokens consumió mi prompt?

  • prompt_tokens: Cantidad de tokens calculados a partir de la entrada del usuario y mensajes de sistema.
  • completion_tokens: Cantidad de tokens generados de forma auto-regresiva por el modelo hasta alcanzar la condición de parada (finish_reason: "stop").
  • total_tokens: Suma total sobre la cual se calculan los costos y límites de cuota (Rate Limits por minuto).

Q&A: ¿Cómo calcular el costo financiero en USD de una llamada? 1 fórmula explicada

Multiplicando los prompt_tokens por la tarifa de entrada por millón (ej: $0.05 / 1M en Llama 3.1 8B) y los completion_tokens por la tarifa de salida (ej: $0.08 / 1M), sumando ambos resultados.

Consejo Pro: Reducción de Latencia Percibida con Streaming

En interfaces de usuario web, habilita siempre stream=True. Aunque la latencia total sea similar, el usuario percibe una respuesta instantánea al ver aparecer los tokens en menos de 150 ms (Time-to-First-Token).

Paso 5 · Celda 6

MIDIENDO LA LATENCIA DE INFERENCIA

Latencia y Rendimiento en Arquitecturas de Producción

Elegir el tamaño correcto de modelo es una decisión de ingeniería, no solo de potencia bruta. Vamos a medir cuánto tarda Llama en responder el mismo prompt.

  • Time-to-First-Token (TTFT): Tiempo transcurrido desde que se envía la consulta hasta que se recibe el primer token generado.
  • Inter-Token Latency (ITL): Tiempo promedio entre cada token sucesivo durante el streaming.
  • Throughput Global: Calculado como Tokens Totales / Duración en Segundos.
05_medicion_latencia.py 
# Medir el tiempo de respuesta de Llama para el mismo prompt

import time

inicio = time.time()
response_tiempo = client.chat.completions.create(
    model=modelo_ligero,
    messages=[{"role": "user", "content": prompt}],
    max_tokens=500
)
duracion = time.time() - inicio

print(f"Tiempo de respuesta: {duracion:.2f} segundos")

Q&A: ¿Por qué la primera llamada puede tardar más que las subsecuentes? 1 causa técnica

Por el establecimiento de la sesión TLS/TCP y la inicialización del socket HTTPS (fase de "Warm-up"). Las llamadas siguientes reutilizan el canal de conexión con menor latencia.

Consejo Pro: Selección Pragmática del Modelo en Producción

Aplica el principio de parsimonia: utiliza siempre el modelo más compacto que cumpla el SLA de calidad requerido. Desplegar un modelo de 120B para FAQs simples incrementa el costo 10x y triplica la latencia sin aportar valor al usuario.

Q&A: ¿Qué es exactamente un "Model Router" en arquitectura de producción? 1 patrón de diseño

Es una capa intermedia de software (proxy) que clasifica la complejidad de la consulta entrante. Si es una pregunta factual o FAQ, la redirige a un modelo ligero (ej: 8B/20B) reduciendo costos y latencia; si detecta razonamiento matemático o código complejo, la escala a un modelo masivo (ej: 70B/120B).

ejecutar_challenge.py 
#!/usr/bin/env python3
"""
Módulo: IA Aplicada con Modelos Abiertos
Challenge: Comparador de Modelos Llama
Alumno: Ing. Jesús Javier Hernández Olvera
"""

import os, re, sys, time, pprint
from pathlib import Path
from dotenv import load_dotenv
from groq import Groq

# 1. Cargar variables de entorno desde .env
env_path = Path(__file__).parent / ".env"
load_dotenv(dotenv_path=env_path)

API_KEY = os.environ.get("GROQ_API_KEY")
if not API_KEY:
    print("Error: Se requiere GROQ_API_KEY en .env")
    sys.exit(1)

client = Groq(api_key=API_KEY)

# Modelos configurados para evaluación
MODELO_LIGERO = "openai/gpt-oss-20b"
MODELO_GRANDE = "openai/gpt-oss-120b"
MODELO_QWEN   = "qwen/qwen3.6-27b"

def limpiar_respuesta(texto):
    if not texto: return ""
    return re.sub(r"<think>.*?</think>", "", texto, flags=re.DOTALL).strip()

# 2. Definición de las 3 Preguntas de Negocio
preguntas = [
    "¿Cómo puedo restablecer mi contraseña olvidada en el portal web institucional?",
    "¿Cuál es el horario de atención y los canales oficiales para soporte técnico?",
    "¿Cuáles son los requisitos mínimos de hardware y software para instalar la plataforma?"
]

# 3. Función de inferencia comparativa
def consultar_pregunta(pregunta: str, num: int):
    print(f"\nProcesando Pregunta {num} en los 3 modelos...")

    # Modelo Ligero (20B)
    t0 = time.time()
    r_lig = client.chat.completions.create(model=MODELO_LIGERO, messages=[{"role":"user", "content":pregunta}], max_tokens=600)
    dt_lig = time.time() - t0

    # Modelo Masivo (120B)
    t1 = time.time()
    r_grd = client.chat.completions.create(model=MODELO_GRANDE, messages=[{"role":"user", "content":pregunta}], max_tokens=600)
    dt_grd = time.time() - t1

    # Modelo Qwen (27B)
    t2 = time.time()
    r_qwn = client.chat.completions.create(model=MODELO_QWEN, messages=[{"role":"user", "content":pregunta}], max_tokens=600)
    dt_qwn = time.time() - t2

    return {
        "pregunta": pregunta,
        "modelo": MODELO_LIGERO,
        "respuesta": limpiar_respuesta(r_lig.choices[0].message.content),
        "tiempo_segundos": round(dt_lig, 2),
        "tokens_prompt": r_lig.usage.prompt_tokens,
        "tokens_respuesta": r_lig.usage.completion_tokens,
        "tokens_totales": r_lig.usage.total_tokens,
        "modelo_grande": MODELO_GRANDE,
        "respuesta_grande": limpiar_respuesta(r_grd.choices[0].message.content),
        "tiempo_grande": round(dt_grd, 2),
        "tokens_grande": r_grd.usage.total_tokens,
        "modelo_qwen": MODELO_QWEN,
        "respuesta_qwen": limpiar_respuesta(r_qwn.choices[0].message.content),
        "tiempo_qwen": round(dt_qwn, 2),
        "tokens_qwen": r_qwn.usage.total_tokens
    }

# 4. Ejecución y consolidación
resultado_1 = consultar_pregunta(preguntas[0], 1)
resultado_2 = consultar_pregunta(preguntas[1], 2)
resultado_3 = consultar_pregunta(preguntas[2], 3)

resultados = [resultado_1, resultado_2, resultado_3]

# 5. Despliegue de Resultados
print("\n" + "=" * 120)
print("TABLA COMPARATIVA CONSOLIDADA (SALIDA DEL CHALLENGE 1):")
print("=" * 120)
for i, r in enumerate(resultados, 1):
    print(f"{i}. {r['pregunta'][:35]}... | Ligero: {r['tiempo_segundos']}s ({r['tokens_totales']} tok) | Grande: {r['tiempo_grande']}s ({r['tokens_grande']} tok) | Qwen: {r['tiempo_qwen']}s ({r['tokens_qwen']} tok)")
print("=" * 120)
