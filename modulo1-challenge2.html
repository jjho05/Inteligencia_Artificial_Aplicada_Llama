1. Fundamentos Matemáticos de RAG y Búsqueda Vectorial

1.1 Bi-Encoders Vectores densos de 384 dimensiones y normalización L2

A diferencia de los LLMs autorregresivos (que generan texto secuencialmente), un modelo Bi-Encoder como paraphrase-multilingual-MiniLM-L12-v2 proyecta cualquier oración a un espacio continuo de \(d = 384\) dimensiones, capturando su significado semántico subyacente.

Cuando los vectores se normalizan mediante norma euclidiana unitaria (\(\|\mathbf{u}\| = 1\)), el cálculo de la Similitud Coseno se reduce exactamente al Producto Punto:

$$\text{Similitud Coseno}(\mathbf{u}, \mathbf{v}) = \frac{\mathbf{u} \cdot \mathbf{v}}{\|\mathbf{u}\|_2 \cdot \|\mathbf{v}\|_2} \xrightarrow{\|\mathbf{u}\| = \|\mathbf{v}\| = 1} \mathbf{u} \cdot \mathbf{v} = \sum_{i=1}^{384} u_i \cdot v_i$$

Esto permite a NumPy o a motores vectoriales calcular similitudes semánticas sobre millones de fragmentos en fracciones de milisegundo.

# Challenge 2: Asistente de Políticas con RAG
# Alumno: Ing. Jesús Javier Hernández Olvera
# Módulo: IA Aplicada con Modelos Abiertos

import os, re, sys, time, argparse
import numpy as np
from sentence_transformers import SentenceTransformer
from groq import Groq
from dotenv import load_dotenv

load_dotenv()
client = Groq(api_key=os.environ.get("GROQ_API_KEY"))

# 1. Base de Conocimiento de Políticas
documentos = [
    "Criterios de Evaluación y Calificación Mínima: Challenges 40%, Proyecto 50%, Masterclasses 10%. Mínimo aprobatorio: 80/100.",
    "Política de Entregas Tardías y Penalizaciones: Límite domingo 23:59 hrs. Hasta 24h: -15 pts. De 24 a 48h: -30 pts. >48h: 0 pts.",
    "Integridad Académica y Asistencia: 80% asistencia mínima a sesiones sincrónicas. Plagio causa baja definitiva del programa."
]

# 2. Embeddings y Búsqueda Semántica
emb_model = SentenceTransformer('paraphrase-multilingual-MiniLM-L12-v2')
embs_docs = emb_model.encode(documentos, normalize_embeddings=True)

def buscar_fragmento(pregunta):
    emb_p = emb_model.encode([pregunta], normalize_embeddings=True)
    sims = np.dot(embs_docs, emb_p.T).flatten()
    idx = int(np.argmax(sims))
    return documentos[idx], float(sims[idx]), idx

# 3. Consulta RAG Delimitada
pregunta = "¿Cuál es la penalización por entregar un challenge con 20 horas de retraso y cuál es la calificación mínima para aprobar el curso?"
frag, score, idx = buscar_fragmento(pregunta)

prompt_rag = f"Responde la pregunta basándote ÚNICAMENTE en el siguiente fragmento oficial. Si algún dato no aparece, acláralo honestamente y no lo inventes.\\n\\nReglamento:\\n\\\"\\\"\\\"{frag}\\\"\\\"\\\"\\n\\nPregunta:\\n{pregunta}\\n\\nRespuesta:"

res = client.chat.completions.create(
    model="openai/gpt-oss-20b",
    messages=[{"role": "user", "content": prompt_rag}],
    max_tokens=800
)
print(res.choices[0].message.content)

4. Preguntas Frecuentes de Sistemas RAG

¿Por qué el modelo declara honestamente que no conoce la calificación mínima cuando usa RAG?

Porque el fragmento recuperado sobre entregas tardías no contiene la cláusula de calificación mínima (que está en el Doc #1). Al instruir explícitamente al LLM: 'Si algún dato no aparece en el fragmento, acláralo honestamente y no lo inventes', se suprime la alucinación probabilística y se garantiza una respuesta 100% auditable.

¿Por qué la similitud coseno equivale al producto punto en este challenge?

Porque al usar normalize_embeddings=True, cada vector se escala a norma euclidiana unitaria (||u|| = 1). La fórmula cos(θ) = (u · v) / (||u|| * ||v||) se simplifica exactamente a u · v, permitiendo a NumPy ejecutar la búsqueda semántica en microsegundos con np.dot().

¿Cómo escalar este pipeline a miles de PDFs corporativos?

Para más de 10,000 documentos se reemplaza NumPy por una Base de Datos Vectorial especializada (ChromaDB, Pinecone, FAISS o Qdrant) que utiliza índices de grafos HNSW (Hierarchical Navigable Small World) para buscar entre millones de vectores en menos de 15 milisegundos.
