El reto definitivo de ingeniería de software para el Módulo 2. Inspección de entrada para abortar de inmediato intentos de inyección de prompt o secuestro del sistema.

Resolución en dos pasos con schemas JSON formales para consultar inventario, citas y pedidos reales.

4. Llama Guard 3 & Docker

Auditoría ética de salidas (MLCommons) y contenedor Docker multi-stage optimizado para producción.
