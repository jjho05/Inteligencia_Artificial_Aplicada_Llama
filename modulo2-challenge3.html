Teoría de Function Calling y Latencia de Ciclo ($T_{total}$)

La experiencia del usuario en WhatsApp no depende únicamente del tiempo que Llama tarda en generar texto; depende de la acumulación de todas las fases del ciclo conversacional y de la ejecución externa de herramientas.

Presupuesto de Tiempo E2E Latencia Acumulada de Inferencia en Dos Pasos
$$T_{total} = T_{webhook} + T_{llama\_call} + T_{exec\_tool} + T_{llama\_synth} + T_{meta\_send} \le 3000\text{ ms}$$
Desglose Exhaustivo de las 5 Fases de Latencia ▼
  • $T_{webhook}$: Tiempo de recepción, validación de firma HMAC y extracción de datos del webhook (~30-50 ms).
  • $T_{llama\_call}$: Primera llamada a Llama para razonar sobre la intención y emitir el JSON de la herramienta (~300-600 ms en Groq LPU).
  • $T_{exec\_tool}$: Ejecución en tu backend de la función real (consulta SQL, CRM o API de inventario, ~100-250 ms).
  • $T_{llama\_synth}$: Segunda llamada a Llama con el resultado inyectado para redactar el mensaje conversacional final (~400-800 ms).
  • $T_{meta\_send}$: Petición HTTP POST a Meta Graph API para entregar el mensaje en el teléfono del usuario (~200-400 ms).

Implementación de Producción

Código Python: Orquestación de Function Calling en 2 Pasos

from groq import Groq
import json

client = Groq()

def resolver_function_calling(mensajes: list, tools_catalog: list):
    # Paso 1: Inferencia con catalogo de herramientas
    response = client.chat.completions.create(
        model="llama-3.3-70b-versatile",
        messages=mensajes,
        tools=tools_catalog,
        tool_choice="auto"
    )
    msg = response.choices[0].message
    if not msg.tool_calls:
        return msg.content

    # Paso 2: Ejecucion local del tool call
    call = msg.tool_calls[0]
    args = json.loads(call.function.arguments)
    resultado = ejecutar_herramienta_local(call.function.name, args)

    mensajes.append(msg)
    mensajes.append({"role": "tool", "tool_call_id": call.id, "content": json.dumps(resultado)})

    # Paso 3: Sintesis final conversacional
    synth = client.chat.completions.create(
        model="llama-3.3-70b-versatile",
        messages=mensajes
    )
    return synth.choices[0].message.content
